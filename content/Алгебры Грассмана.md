n-Мерная [[Алгебра]] Грассмана генерируется $\theta_1, ..., \theta_n$: 
$$ \{\theta_i, \theta_j\} = 0, \ \ \ \ \ \ \ i,j = 1, 2, ... ,n $$
# Диференциирование и интегрирование 
#### **Для 1 переменной**

$\{\theta, \theta\}=0$,        $p(\theta) = P_0 + \theta P_1$. 

*Можна дифференциировать слева и справа: 
$$ \dfrac{d}{d\theta}\theta =\theta\dfrac{\overset\leftarrow{d}}{d\theta}=1, \ \ \ \ \ \ \ \ \ \  \dfrac{d}{d\theta}p(\theta) =1, \ \ \ \ \ \ \ \ \ \ p(\theta)\dfrac{\overset\leftarrow{d}}{d\theta}=-1$$

*Определение интеграла:
1. Инвариант при сдвиге $$ \int d\theta p(\theta) =\int d\theta p(\theta + \alpha) \Rightarrow \int d\theta = 0 $$
2. Нормализация
$$ \int d\theta\theta = 1$$
3. Замена $\theta \rightarrow a + b\theta$, где $a$ - антикоммутирующее, а $b$ - [[с-числа|с-число]]
	1. Для с-чисел
				$$ \int d \tilde{x} f(\tilde{x}) = \int d x \left(\frac{d\tilde{x}}{dx}\right) f(\tilde{x}(x)) $$
	2. Для такой замены:
	$$ \int d \tilde{\theta} f(\tilde{\theta}) = \int d \theta \left(\frac{d\tilde{\theta}}{d\theta}\right)^{-1} f(\tilde{\theta}(\theta)) $$



На основе предоставленных изображений, вот краткая сводка ключевых понятий об **алгебре Грассмана**:

### 🏛️ 1. Определение и назначение

- **Назначение:** Алгебра Грассмана — это математический аппарат, используемый для описания **фермионных полей** (таких как $\psi(x)$) в квантовой теории поля, в частности, в рамках функционального интеграла.
    
- **Генераторы:** $n$-мерная алгебра Грассмана задается набором из $n$ образующих (генераторов) $\theta_1, \theta_2, \dots, \theta_n$.

---

### 🧮 2. Ключевые свойства

- Антикоммутация: Фундаментальное свойство генераторов — они антикоммутируют друг с другом. Для любых $i, j$:
    
    $$\{\theta_i, \theta_j\} \equiv \theta_i \theta_j + \theta_j \theta_i = 0$$
    
- Нильпотентность ($\theta^2=0$): Прямым следствием этого является то, что квадрат любого отдельного генератора равен нулю:
    
    $$\theta^2 = 0$$
    
- **Конечный ряд:** Из-за свойства $\theta^2=0$ любой общий элемент алгебры $p(\theta)$ (который является многочленом от $\theta$) представляет собой **конечный ряд**, который обрывается.
    

---

### 📐 3. Особое исчисление (интегрирование и дифференцирование)

Для грассмановых переменных определены специальные операции, которые отличаются от обычного анализа.

- **Определение:** Интегрирование и дифференцирование для антикоммутирующих величин формально определяются так, чтобы обладать интуитивными свойствами (например, инвариантность при сдвиге).
    
- **Ключевые правила интегрирования:** Для одного элемента $\theta$ действуют два основных правила:
    
    1. $\int d\theta = 0$
        
    2. $\int d\theta \, \theta = 1$ 
        
- **Эквивалентность:** Подчеркивается, что для антикоммутирующих величин **интегрирование эквивалентно дифференцированию**.
    
- **Вторая производная:** Вторая производная от грассмановой функции всегда равна нулю: $d^2/d\theta^2 \, p(\theta) = 0$.
    

---

### 🚀 4. Гауссов интеграл (Главное применение)

Основная причина введения этой алгебры — вычисление гауссовых интегралов, которое дает результат, **обратный** обычному (бозонному) случаю.

- **Обычный (Бозонный) Гауссов интеграл:** $\int dx \exp(-\frac{1}{2} x A x) \sim \frac{1}{\sqrt{\det A}}$.
    
- **Фермионный (Грассманов) Гауссов интеграл:**
    
    - Для вещественных полей (генераторов $\theta$):
        
        $G(A) = \int d\theta_n \dots d\theta_1 \exp\left(\frac{1}{2}\theta A \theta\right) = \sqrt{\det A}$
        
    - Для комплексных полей (фермионные поля $\psi, \bar{\psi}$):
        
        $W = \int [d\bar{\psi}][d\psi] \exp\left\{ \int d^4x \bar{\psi} A \psi \right\} = \det A$

Этот результат ($\det A$ в числителе) напрямую ведет к известному правилу Фейнмана: **каждая замкнутая фермионная петля в диаграмме дает дополнительный множитель (–1)**.



$\int d\theta_n \dots d\theta_1 p(\theta) = \int d\theta_n \dots d\theta_1 [\det(d\theta/d\bar{\theta})] p(\bar{\theta}(0))$
$$
\int d\theta_{n}\dots d\theta_{1}p(\theta) = \int d\theta_{n}\dots d\theta_{1}\det\left( \frac{d\theta}{d\bar{\theta}} \right)p(\bar{\theta}(0))
$$
