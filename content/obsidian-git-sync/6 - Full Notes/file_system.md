### Файлова система

**Означення:** Блочний пристрій - бітове поле
**Приклад:** 01101011 10101101 01010100 ...

**Означення:** Файл - дані, розміщені на поіменованій ділянці носія даних.

**Означення:** Файлова система - система, що надає абстрацію роботи з файлами на основі блочного пристрою.

У файлових системах Linux службові дані зберігаються окремо від корисних у **inode-ах**.Inode-и містять посилання на початок і кінець блоку, де зберігаються корисні дані.

**Зауваження:**  Видалення файлу - видалення відаовідного inode-a, самі дані залишаються на диску, поки не будуть перезаписані.

**Означення:** Супреблок - частина файлової системи, що містить інформацію про всю файлову систему загалом:
- Розмір таблиці inode-дів
- Положення inode-в у пам'яті
- Різноманітну допоміжну інформацію

#### Директорія
Зберігає відповідність імені файлу номеру inode-a.
**Зауваження:**  Сам файл "на знає свого імені", воно міститься в директорії.

**Означення:** Жорстке посилання - альтернативне ім'я фалйлу. Жорстке посилання - це просто ще один inode, що вказує на той же файл. Символьне - файл у файловій системі, що містить місце файла у файловій системі (що містить id inode-a з файлом).


### Адресація
**Master Boot Record(MBR)** - перший блок пристрою, що містить 512 байт:
- 446 байт - завантажувач (ініціалізатор файлової системи)
- 64 байти - розмітка
- 2 байти - підпис 0x55AA

Розмітка може містити максимум 4 розділи (інфа про 1 розділ - 16 байт).

**Означення:** Розділ - окрема частина блочного пристрою зі своєю файловою системою.

Щоб отримати більше 4 розділів, треба розбити один з розділів на логічні томи (перетворити його на **Extended**). Розділ, що не розбивається на логічні томи, називається **Primary**. 

**Extened Boot Record(EBR)** - аналог MBR для логічного тому.

**Зауваження:** Логічні томи зберігаються ланцюжком (кожен том, починаючи з extended, містить посилання на наступний).
