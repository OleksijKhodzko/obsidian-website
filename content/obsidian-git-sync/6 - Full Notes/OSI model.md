# OSI model

tags: [[networking]]

Consists of 4 levels

### Application
Generates and receives data.

### Transport
Uses [[TCP]] or [[UDP]] to transport data inside local network.

### Internet
Adds [[IP]] header, which includes both ips.

### Network interface
The lowest, physical level of TCP/IP. Includes hardware addresses in header.

Physical - data, cables (for example, cat6)
Data - [[switching]] and mac addresses
Network - [[IP|ip adresses]], [[routing]]
Transport - [[TCP]], [[UDP]]
Session - [[session management]]
Presentation - [[WMV]], [[JPEG]],[[MOV]]
Application - [[HTTP]], [[SMTP]]
