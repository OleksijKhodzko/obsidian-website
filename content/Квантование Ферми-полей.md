# Каноничное квантование для фермионов

1. Свободное поле Дирака: 
$$\mathcal{L}(x) = \overline{\psi}(x)(i\gamma\partial_\mu - m)\psi(x).$$
2. Уравение Дирака: 
$$(i\gamma\partial_\mu - m)\psi(x) = 0.$$
3. Феймновский пропагатор: 
$$ iS_F(x_1-x_2)_{\alpha\beta} = \bra0T(\psi_\alpha(x_1)\overline\psi_\beta(x_2))\ket0 = \int\frac{d^4k}{(2\pi)^4}\left( \frac{i}{k - m + i\varepsilon} \right)_{\alpha\beta} e^{-ik(x_1 -x_2)} $$
4. Из-за антикоммутационных соотношений есть наличие минуса для каждой замкнутой фермионной петли в фейнмановсой диаграм
