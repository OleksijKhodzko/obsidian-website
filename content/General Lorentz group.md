# Definition of the general Lorentz group
Condition
$$
\hat{L}^{T}\eta \hat{L}=\eta. \ \ \ (3)
$$
for [[Lorentz transform]] implies that $L^{-1}, \ L_{1}L_{2}$ and $I_{4}$ are Lorentz transforms if $L,\ L_{1}$ and $L_{2}$ are. Therefore it's a group.
# Connectedness
General Lorentz group is disconnected.
From $(3)$ we have $\det L=\pm 1.$ 
By plugging $\rho=\lambda=0$ into
$$
L^{\mu}_{\ \ \ \rho}L^{\nu}_{\ \ \ \lambda}g_{\mu\nu}=g_{\rho\lambda} \ \ \ (2)
$$
we get 
$$
(L^{0}_{\ \ \ 0})^{2} = 1 + \sum(L^{i}_{\ \ \ 0})^{2} \implies |L^{0}_{\ \ \ 0}|\geq 1.
$$
So we have 4 groups:

|                                         |                                        |
| --------------------------------------- | -------------------------------------- |
| 1) $\det L=1$, $L^{0}_{\ \ \ 0}\geq 1$  | 2) $\det L=1$, $L^{0}_{\ \ \ 0}\leq 1$ |
| 3) $\det L=-1$, $L^{0}_{\ \ \ 0}\geq 1$ | 4) $\det L=1$, $L^{0}_{\ \ \ 0}\leq 1$ |
$\det L=1$, $L^{0}_{\ \ \ 0}\geq 1$ - *proper* *orthocronous* transform $L_{+}^{\uparrow}$.
